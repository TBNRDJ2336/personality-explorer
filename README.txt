PERSONALITY EXPLORER — VS CODE PROJECT

Files:
- index.html: website structure and content
- css/style.css: colours, layout, animations, and responsive design
- js/script.js: quiz questions, navigation, and results
- assets/images/: optional folder for your own images

HOW TO RUN:
1. Extract the ZIP file.
2. Open the personality_explorer folder in VS Code.
3. Open index.html.
4. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   You can also open index.html directly in your browser.

The quiz is a fun self-reflection activity, not a clinical or scientifically validated assessment.
The Google Fonts connection requires internet; the site still works with fallback fonts if offline.
